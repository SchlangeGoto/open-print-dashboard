## OpenPrintDash 0.1.2

This release brings the mobile app to feature parity, adds filament pricing and
push notifications, and hardens auth and filament accounting.

### Highlights

- **One mobile app for Cloud and self-hosted** — pick the hosted service or
  enter your own server at first launch.
- **Phone controls** — pause, resume and cancel the active print after an
  explicit confirmation; the command is bound to the job you confirmed.
- **Filament and spool editing on the phone** — material details, default
  price, remaining weight, notes and delete flows.
- **Default price per filament** — new, scanned and AMS-created spools inherit
  it; existing spools keep their recorded price.
- **Push notifications** — print finished/failed and spool loaded, with
  per-device registration and cleanup.
- **Dashboard motion** — spool fill animation, staggered cards, count-up stats
  and reduced-motion support.

### Fixes

- Deactivating a user revokes every session immediately.
- Legacy print jobs can no longer charge the rolls loaded today.
- Deferred deduction retries never resolve unrecorded slots against a later tray.
- Deleted recorded rolls charge the surviving rolls instead of the whole job.
- Demo mode exits cleanly and no longer leaves stale state.

### Upgrade notes

- Containers (`compose.ghcr.yml`): unset any exported `IMAGE_TAG` first, set
  `IMAGE_TAG=0.1.2` in `.env`
  (`IMAGE_PREFIX=ghcr.io/schlangegoto/open-print-dashboard`), then
  `docker compose -f compose.ghcr.yml pull && docker compose -f compose.ghcr.yml up -d`.
  Containers run `alembic upgrade head` on start.
- Source deployments: update the checkout and rebuild
  `docker compose -f compose.prod.yml up -d --build`. The backend container
  runs migrations on start; PostgreSQL 16+ is still required.
- Android: the signed APK is attached below. Remote push needs a development
  or release build and FCM/APNs credentials configured in EAS.
