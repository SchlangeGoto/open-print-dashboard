## OpenPrintDash 0.1.0

First release of the self-hosted OpenPrintDash dashboard.

- Docker Compose deployment for the backend, frontend and site.
- Bambu Lab cloud printers, spools, filaments, print history and analytics.
- Android APK for the mobile app.

**Full changelog:** https://github.com/SchlangeGoto/open-print-dashboard/commits/v0.1.0
